# Living Intermediate Control Plane

Version **0.6.0**

## Unattended (self-maintain under gates)

```bash
plane unattended
npm run unattended
```

Runs daily loop + auto workspace tasks + final verify/doctor.  
See `docs/unattended.md`.

## Daily / manual

```bash
plane daily
plane checklist
plane procure
```

## Success criteria

1. Readiness is READY  
2. Evidence is available (public or local accepted)  
3. Supply-chain enforcement stays active
