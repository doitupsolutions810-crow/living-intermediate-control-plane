# Living Intermediate Control Plane

Version **0.4.1**

## Quick start

```bash
npm run init
npm run next
npm run procure
npm run doctor
npm run security-summary
```

## Success criteria

1. Readiness is READY  
2. Evidence is available (public or local accepted)  
3. Supply-chain enforcement stays active  

## Useful commands

```bash
npm run next
npm run procure
npm run procure:gated
npm run dry-run
npm run doctor
npm run security-summary
npm run ci
npm run docker:build
npm run help
```

## Note

CI is a helper. Readiness and doctor remain the authority for limited-technicality decisions.
See `docs/security.md`.
