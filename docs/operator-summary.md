# Operator Summary

**First time / setup**

```bash
npm run init
```

**Daily command**

```bash
npm run procure
```

**Quick views**

```bash
npm run snapshot
npm run health
npm run info
npm run report
npm run last
npm run help
```

**Safe preview**

```bash
npm run dry-run
```

**Control**

```bash
npm run pause
npm run resume
npm run state
npm run log
npm run actions
```

**Background**

```bash
npm run continuous
npm run watch
```

**Maintenance**

```bash
npm run smoke
npm run reset-local -- --confirm
npm test
```

## Success criteria (only three)

1. Readiness is READY
2. Evidence is available (public or local accepted)
3. Supply-chain enforcement remains active
